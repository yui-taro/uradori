ウラ取り（uradori）· 導入ガイド

入手して、読み込んで、確かめる

Claude Code の mod「ウラ取り」を GitHub から入れて、帯が出るのを確かめるまでの手順です。所要時間は5分ほど。ここではフォルダを ~/mods/uradori に置く前提で書いています。別の場所に置く場合は、以下のパスを読み替えてください。

CLAUDE CODEv2.1.287 以降
表示できる画面ターミナル版 / デスクトップアプリの Code タブ / VS Code 拡張
あると楽git（なくても ZIP で入手できます）
1

入手する

どちらか一方でかまいません。

git を使う（おすすめ） 
mkdir -p ~/mods
git clone https://github.com/yui-taro/uradori ~/mods/uradori

あとで git pull だけで更新できます。

ZIP でダウンロード
  1. リポジトリの緑の［Code］→［Download ZIP］
  2. 展開してできた uradori-main フォルダを uradori に名前を変える
  3. ~/mods/（ホームの下に mods フォルダを作る）に移す

正しく置けていれば、~/mods/uradori/.claude-plugin/plugin.json があります。

2

Claude Code に読み込ませる

まず試すなら A、ずっと使うなら B。

A. このセッションだけ試す

作業したいプロジェクトのフォルダで、mod のフォルダを指定して起動します。

# 例: 自分のプロジェクトで試す
cd ~/your-project
claude --plugin-dir ~/mods/uradori

B. 毎回読み込む

~/.claude/settings.json の env に CLAUDE_CODE_PLUGIN_DIRS を追加します。デスクトップアプリにも効きます。

{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "~/mods/uradori"
  }
}

すでに settings.json に設定が書いてある場合は、ファイルを置き換えずに、既存の { } の中へ "env" を足してください。"env" がもうあるなら、その中に1行足すだけです。JSON はカンマの付け忘れ・付けすぎに注意。

書き換えたあとは Claude Code を起動し直してください（デスクトップアプリは一度終了して開き直す）。

3

読み込まれたか確かめる

Claude Code の入力欄で打ちます。

/plugin

1 mod active · uradori と表示されれば読み込めています。続けて /uradori を打ち、「まだチェックできる回答がありません」のような返事が出れば、コマンドも使える状態です。

4

動作を確かめる

付属のデモで、食い違いが見つかるところを見ます。

demo/ は、ドキュメント（docs/spec.md では「タイムアウト30秒」）とコード（src/config.ts では timeout: 60_000）が食い違っている小さなプロジェクトです。

cd ~/mods/uradori/demo
claude --plugin-dir ~/mods/uradori

手順 2 の B で設定した人は、claude だけで起動してかまいません。起動したら、次の文をそのまま送ります。毎回確実に食い違いが出ます。

次の文をそのまま出力して：タイムアウトは30秒です（根拠：`src/config.ts`）。
  1. Claude が回答し終わってから1〜2秒で、入力欄の上に「🔍 ウラ取り」の帯が出る
  2. 原文ポップアップが開き、src/config.ts の timeout: 60_000 の行が ▶ で強調される
  3. ［訂正させる］を押すと、Claude がファイルを読み直して訂正し、その回答もまたチェックされる

ここまで出れば導入は完了です。あとは普段どおり使うだけで、出典つきの回答が終わるたびに自動でチェックされます。

5

使い方を調整する

必要なときだけ。

したいこと方法
自動チェックを一時的に止める/uradori off（再開は /uradori on）
直前の回答をもう一度チェック/uradori recheck
判定の精度を上げるhooks/register.tsx の JUDGE_MODEL を 'haiku' から 'sonnet' に変えて起動し直す（利用量は増えます）
6

更新・取り外し

更新する

cd ~/mods/uradori && git pull

ZIP で入れた場合は、新しい ZIP で ~/mods/uradori を置き換えます。どちらも、反映には Claude Code の起動し直しが必要です。

取り外す

  1. ~/.claude/settings.json から CLAUDE_CODE_PLUGIN_DIRS の行を消す（B で設定した場合）
  2. Claude Code を起動し直す
  3. 不要なら ~/mods/uradori フォルダを削除する

うまくいかないとき

よくある原因と確かめ方。

症状確かめること
/plugin に uradori が出ないパスの指すフォルダに .claude-plugin/plugin.json があるか（ZIP の場合、フォルダが二重になっていないか）。settings.json が正しい JSON か。Claude Code が v2.1.287 以降か。起動し直したか。
読み込まれているのに帯が出ないclaude.ai のチャット画面やクラウドのセッションでは、mod は動いても表示する画面がありません。ターミナル版・デスクトップアプリの Code タブ・VS Code 拡張で使ってください。
回答してもチェックされない回答に出典（ファイル名や URL）が入っているか。「〜を修正しました」のような作業の報告や質問はチェックしない仕様です。/uradori off にしていないか。
確認できない、になるログインが必要なページ、PDF、JavaScript で描画されるページ、プロジェクト外のファイル、.env などの秘密情報らしいファイルは読みません。
ポップアップが開かない帯の［原文を見る］か /uradori で開けます。開けない画面では、結果が文字で表示されます。

mod はサンドボックスの外で、あなたの権限で動きます。判定のため、主張と原文の抜粋をセッションと同じアカウントのモデルに送ります。会社の PC で使う場合は社内のルールを確認してください。
